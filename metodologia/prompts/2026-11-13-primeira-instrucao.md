# Prompt 001: primeira instrução (13/11/2026)

**Técnicas:** role prompting, decomposição e guardrails.

**Resumo do pedido:** seguir a seção 22 do planejamento v1.3. Os passos eram:

1. Diagnosticar o ambiente.
2. Criar a estrutura semântica de pastas.
3. Escrever `CLAUDE.md` e os documentos de gestão.
4. Iniciar o Git local, sem remoto.
5. Montar a fundação React/Vite/Tailwind/Vitest.
6. Criar a tela Saúde do sistema e o catálogo de agentes e habilidades, com autotestes.
7. Criar as skills, os subagentes e o hook em `.claude/`.
8. Rodar o build e os testes, com evidências.

**Limites:** parar antes de criar contas, configurar Supabase ou OAuth, fazer qualquer ação no GitHub ou gerar custos. Não pedir senhas.

**Nome do projeto**, definido pelo usuário durante a execução: GUARÁ (Gestão Unificada de Análises, Rotinas e Apoio).

**Resultado:** ver `metodologia/evidencias/2026-11-13-etapa-1-2.md`.
