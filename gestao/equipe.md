## Observações

- Em repositório pessoal, o GitHub convida pelo **nome de usuário** (Settings → Collaborators → Add people). Convite por e-mail só funciona em organizações. Por isso, é preciso obter o usuário GitHub do colaborador.
- O papel de cada integrante e o nível de permissão (leitura, escrita ou manutenção) ainda precisam ser confirmados.
- **Nenhum convite foi enviado** e o repositório remoto ainda não existe. As duas ações dependem de autorização do responsável.
