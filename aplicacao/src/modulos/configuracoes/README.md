# Configurações

Tela de preferências do analista. Hoje tem só a seção **Mascotes**: escolha do mascote principal e nome de cada um (até 20 caracteres; vazio mostra a espécie).

As preferências ficam em `compartilhado/preferencias-mascote.ts` (chave `guara:mascote:v1` no localStorage), porque o painel do assistente também as lê. São só visuais: não mudam permissões, dados nem capacidades (seção 7.3 do planejamento).
